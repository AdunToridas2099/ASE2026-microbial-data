# microbial data

Data files associated with the study **Microbial community assembly and functional potential in saline-alkali paddy soils under different fertilization regimes**.

## Files

| File | Contents | Format |
| --- | --- | --- |
| `otu_table.xls` | OTU abundance table: 8,042 OTU rows and 72 sample columns. | Tab-delimited text. |
| `otus.fa` | 9,122 OTU representative sequences. | FASTA. |
| `kegg.profile.L3.xlsx` | KEGG level 3 profile table; worksheet `kegg.profile.L3`, 349 nonempty data rows and 18 sample columns. | Excel workbook. |

The original filenames and file contents are preserved. Sample identifiers are retained as supplied.

## OTU identifiers

All 8,042 OTU identifiers in `otu_table.xls` are present in `otus.fa`. The FASTA file also contains 1,080 additional OTU identifiers that are not rows in this abundance table. Both files are provided without filtering or modification.

## File integrity

This upload contains the processed tables and OTU representative sequences listed above.
